# Rheinland Netzwerk Bot-Avatar

Lade dein animiertes Logo als GIF in diesen Ordner und nenne die Datei exakt `logo.gif`.
Der Bot liest `assets/logo.gif` beim Start, wenn `BOT_AVATAR_ON_START=true` gesetzt ist.
Die Datei wird nicht mit dem Repository ausgeliefert, da sie vom Betreiber bereitgestellt wird.
